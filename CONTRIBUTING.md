# Contributing to AeroTouch

Thank you for your interest in improving AeroTouch!

## Development Guidelines
1. Ensure your local Node version is >= 18.
2. Run `npm install` to install dependencies.
3. Verify changes pass all checks:
   - `npm run lint` (Oxlint with React & Accessibility checks)
   - `npm run test:run` (Vitest unit tests)
   - `npm run build` (TypeScript check and Vite production bundle)
4. Do not commit `.env` or sensitive credentials.
5. Create small, focused pull requests with descriptive summaries.
